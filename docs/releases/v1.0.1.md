# CairnKV v1.0.1 — README Rewrite

A documentation-only patch that turns the README from a week-by-week build log
into a v1.0 project overview.

## Highlights

- Reads as a product page first: what CairnKV is, how it is put together, and
  what guarantees it provides.
- New sections: architecture and threading model, write/read paths, failure
  matrix, validation matrix, benchmark methodology, quick start, SDK example,
  project layout, and a docs index.
- Future work (snapshot/InstallSnapshot, lease read, dynamic membership,
  multi-Raft) is now a **Roadmap**, not a list of release gaps.

## Compatibility

- No code, protocol, or on-disk format changes. The only source change is the
  version string (`1.0.0` → `1.0.1`).
- v1.0.0 binaries and data directories remain compatible; downstream users can
  stay on `v1.0.0` or move to `v1.0.1` without migration.

## Validation

- Documentation-only change; `ctest` remains 7/7 on the unchanged v1.0.0 code
  tree.
- Behaviour and performance data are unchanged from v1.0.0; see
  `docs/case-study-w5.md` and `docs/benchmarks/v0.4-baseline.md`.
